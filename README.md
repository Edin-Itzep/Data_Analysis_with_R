📊 Banking Churn Analysis: Detección Estratégica de Abandono
🎯 Objetivo del Proyecto
Este proyecto analiza un dataset de 10,000 clientes bancarios para identificar los factores clave que influyen en la fuga de clientes (churn). El análisis combina limpieza de datos, 
exploración estadística y visualizaciones para proponer estrategias de retención basadas en datos.

🛠️ Stack Tecnológico
Lenguaje: R

Librerías principales: * tidyverse (Manipulación de datos)

ggplot2 (Visualización)

reshape2 / tidyr (Estructuración de matrices)

Reporte: R Markdown (HTML)

📈 Hallazgos Principales (Insights)
Geografía Crítica: Los clientes en Alemania tienen una tasa de fuga del 32%, el doble que en España o Francia.

Correlación Inversa: Se identificó que a mayor saldo en cuenta (Balance), menor es el número de productos contratados, señalando un segmento de alto valor subutilizado.

Perfil de Riesgo: Los clientes con mayor edad (45-60 años) presentan una tendencia de abandono significativamente superior al promedio general.
